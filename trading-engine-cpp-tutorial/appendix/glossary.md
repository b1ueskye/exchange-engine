# 交易与工程术语

| 术语 | 在本课程中的含义 |
| --- | --- |
| Bid / Ask | 买侧委托 / 卖侧委托。买一是最高买价，卖一是最低卖价 |
| BBO | 最优买价与最优卖价，可包含对应聚合量 |
| Spread | 卖一减买一。任意一侧为空时，没有两个可用于求差的价格 |
| Maker / Taker | 撮合时已在簿中等待的一方 / 触发本次匹配的一方。改价可能让挂单主动成交 |
| Tick / Lot | 价格最小步进 / 引擎定义的交易量单位 |
| Price level | 同侧、同价的活动订单档位 |
| GTC | 限价单。余量保留在簿中，等待成交或撤减 |
| IOC | 立刻尝试在限价内成交。未成交余量取消 |
| FOK_BUDGET | 立即全部成交，且买入总额不超过预算或卖出总额达到下限，否则整笔拒绝 |
| L2 | 逐价档的价、总活动量和笔数。课程另用逐订单视图核对 FIFO |
| Reserve bid price | 现货买单计算冻结的预留价。限制允许的改价范围 |
| Pending position size | 期货风险账本中挂单尚待成交的数量，按买卖方向记录 |
| Order ID / Sequence | 订单标识 / 引擎命令位置。一个订单可经多个命令改变 |
| Backpressure | 下游有界容量影响入站接纳。本课程的满队列拒绝发生在命令接受之前 |
| Replay | 把持久化命令按序重新应用到空状态或快照状态 |
| Canonical state | 为比较或序列化规定确定顺序的状态表示。簿的 FIFO 顺序是其中一部分 |
| Required margin | 待成交量与有符号持仓形成的买、卖候选保证金的最大值，不等同于逐订单资金冻结 |
| Last price cache | 最近一次成功命令发布的 L2 买一、卖一；缺失和陈旧缓存也会影响后续准入 |
| Opened size | 本次成交在平掉相反仓位后，新开出的数量；Java 当前期货费用按它计算 |
| Open interest | 单品种多头与空头未平数量，稳定状态应当两侧相等 |
| 语义版本 | 固定业务行为的版本；修正顺序敏感的准入等规则时需与旧日志的回放预期分开 |
