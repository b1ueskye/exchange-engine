# 从零手写交易引擎：32 天 C++ 系统实战

同一价格有两笔卖单排队，新来的买单只够吃掉第一笔和第二笔的一部分。你将在课程里实现这次撮合、解释每个订单的剩余量，再用相同的事件结算两边的账户。后半程用这套规则检查订单簿优化、线程间交接和故障恢复。

课程面向熟悉 Java 后端、第一次用 C++ 完成系统项目的读者。每个「Day」是一篇课。工具链课通常需要 1–2 小时，撮合、结算、并发与恢复课可以分几次完成。课程统一采用 C++20 和 CMake 3.20 起步。

## 从这里开始

1. [Java 架构与核心源码分析](00-overview/java-source-analysis.md)记录当前源码的调用链、订单语义、分片、结算与持久化。
2. [C++ 架构设计](00-overview/architecture.md)给出学习工程的模块边界、订单语义、生命周期和接口演进。
3. [Java 与 C++ 深度对照](00-overview/java-cpp-comparison.md)解释从 Java 迁移时容易带过来的假设。
4. [32 课路线图](00-overview/learning-roadmap.md)逐课列出前置知识、源码、实现任务和验收目标。
5. 下方八个阶段包含 Day 01–32 的完整教程。第八阶段按参考 Java 的风险规则完成期货与集成验收。

## 最终练习目标

完成课程后，你的学习工程应能注册品种和账户，处理限价 GTC、带价限 IOC、带总额约束的 FOK，支持撤单、减量、改价、L2 快照与结果事件。现货主线覆盖资金冻结、成交结算、手续费、查询和余额核对。后半程实现替代订单簿、有界异步入口、快照和日志重放。期货与现货共用账本，保留 Java 当前的盘口估值、保证金、开仓计费和持仓释放规则。最终验收同时覆盖独立产品场景与同币种资金共用。

请在自己创建的 `exchange-lab/` 中跟做。每课完成后提交一个可构建的学习版本，并按[学习进度表](appendix/learning-progress.md)记录接口变化和验收命令。语义约定查阅[架构决策](appendix/architecture-decisions.md)，术语和 C++ 概念可随时回查[术语表](appendix/glossary.md)与 [C++ 概念索引](appendix/cpp-concepts.md)。
